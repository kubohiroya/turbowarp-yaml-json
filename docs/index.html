TurboWarp YAML/JSON

TurboWarp YAML/JSON builds structured data as immutable reporter values. The same data can be rendered as YAML or JSON, and it can be validated with JSON Schema before serving.

Core Flow

pair key [name] value [string [sensor]]
pair key [temperature] value [number [21]]
[name pair] followed by [temperature pair]
map [combined pairs]
render YAML [map result]
render JSON [map result]

Validation Flow

validate JSON Schema [{"type":"object","required":["temperature"]}] data [map result]
JSON Schema [{"type":"object","required":["temperature"]}] accepts data [map result]?

Common Blocks

CategoryBlocks
Scalarsstring, number, boolean, nullValue
Containerspair, map, sequence
Compositionconcat
OutputrenderYaml, renderJson
ValidationvalidateSchema, isValidSchema

HTTP Server Interoperability

For turbowarp-http-server, pass the rendered string as the response body and set Content-Type: application/yaml; charset=utf-8 or Content-Type: application/json; charset=utf-8.

TypeScript API

The package also exports block-free builder functions from @kubohiroya/turbowarp-yaml-json, including stringValue, numberValue, booleanValue, nullValue, pair, map, sequence, concat, renderYaml, renderJson, and validateWithJsonSchema.
